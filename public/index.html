            4. Loyalty QR Settings MODERN

            Controls the rotating Loyalty QR that gets printed on the receipt right after a redemption (so cashiers don't need a separate loyalty-card printout). Hardware/visual setting — not counted in the 2 free customizations.

            "All Printers" is the default — the QR will appear on both on-screen/regular-browser print AND Bluetooth thermal print. Choose one option if you want it to appear on only one type of printer.

            Controls the spacing between the Loyalty QR block and the transaction barcode, regardless of the Position chosen above (Above/Below Barcode).

            Only relevant when "Print 2 copies of the QR side by side" is checked above.

            Larger = easier to scan, but it also takes up more space on the paper.

            No printer paired
            Advanced settings (Service/Characteristic UUID)

            Not all thermal printer brands use the same Bluetooth GATT UUID. The default values here match the most common UUIDs used by generic 58mm/80mm printers. If pairing returns a "Not Found" error, try updating these values based on your printer's manual or specifications.

            🇹🇼 8. Taiwan Receipt Template MODERN

            When this is ON, the entire receipt generated by OmniPOS (store header/logo, item list, totals, transaction barcode, Loyalty QR, footer — everything, NOT just a QR code) is resized to the receipt width commonly used by convenience stores in Taiwan. This is a hardware/visual setting only — it does not count toward the 2 free customizations.

            Default: 57mm — the typical receipt width used by convenience stores in Taiwan. The barcode, Loyalty QR, and every other receipt element automatically scale to fit within this width, so nothing gets cut off at the edge at any width setting. Still capped by the physical paper loaded in the printer.

            Ipinapakita na ng Preview ang iyong mga pagbabago sa itaas kahit hindi pa na-Save — ligtas itong subukan nang paulit-ulit, HINDI ito kumokonsumo ng free credits. Ang "Save" (o "Save Taiwan Template Settings") pa rin ang tanging gumagamit ng 1 sa 2 free na pagbabago, kaya i-Preview muna bago i-Save kung sakaling magkamali. Sample/dummy data lang ang gamit dito — hindi ito totoong transaksyon.

            9. Transaction ID Format (hardware setting — not counted in the 2 free customizations)

            Piliin kung gaano kaikli o kahaba ang Transaction ID (Reference Code) na ginagawa kada matagumpay na benta — lumalabas ito sa resibo, History, at sa ilalim ng barcode. Mula sa pinakaikli hanggang sa orihinal/lumang format na dati'y iisa lang ang meron. Ang pinakaikli ang default ngayon.

            Live Preview (sample ID lang, hindi totoong benta)

            Tandaan: mas maikli ang ID, mas mataas (kahit paano) ang tsansa ng pagkaka-duplicate sa napakadaming benta — sapat pa rin ito para sa karaniwang paggamit ng isang tindahan/terminal. Hindi apektado ang mga Transaction ID ng mga NAUNANG benta — ang bagong format lang ang gagamitin sa mga SUSUNOD na benta.

            Customer-Facing Display

            Opens a second screen (e.g. a monitor or tablet facing the customer) that mirrors the live cart and shows a thank-you screen after each sale.

            AI-Powered Fraud & Anomaly Detection

            Automatically flags unusual discounts, rapid void/refund activity, oversized refunds, and off-hours sales by comparing each cashier's activity against their own history. Detected incidents never block a sale — they only get logged to the Fraud Alerts tab (and optionally emailed).
