            Frequently ask Question (FAQ)

            Piliin ang tanong sa ibaba, o mag-search sa taas, para malaman kung paano gamitin ang OmniPOS.

            Karaniwang Tanong (Common Questions)

            Ano ang OmniPOS?

            Ang OmniPOS ay isang Point-of-Sale (POS) system na ginagamit para sa pagbenta, pagmonitor ng imbentaryo, pag-print ng resibo/barcode, at pagsubaybay sa mga transaksyon at user ng tindahan o negosyo.

            Paano mag-checkout o magbenta gamit ang POS Terminal?

            Pumunta sa POS Terminal sa sidebar, piliin o i-scan ang mga produktong bibilhin para maidagdag sa cart, tapos pindutin ang Checkout para makumpleto ang benta. Awtomatikong mababawas ang stock ng produkto pagkatapos ng checkout.

            Paano magdagdag ng bagong produkto sa Inventory?

            Pumunta sa Inventory → Products, tapos hanapin ang button para magdagdag ng bagong item. Puwede ring mag-import ng maramihang produkto gamit ang Excel/CSV template na available sa parehong page.

            Paano gumawa o mag-print ng barcode?

            Pumunta sa Inventory → Barcode. Doon mo makikita ang barcode generator para sa mga produkto mo, na puwedeng i-print para gamitin sa pag-scan tuwing may benta.

            Saan ko makikita ang kabuuang benta at pinaka-bestseller na produkto?

            Sa Sales Report makikita ang gross income, bilang ng transaksyon, at ranking ng top-selling na produkto.

            Paano ma-void o makansela ang isang transaction?

            Pumunta sa Transaction, hanapin ang order na gustong i-void, tapos pindutin ang void option. Hihingan ka ng Admin password bago matuloy — awtomatiko ring ibabalik ang stock sa imbentaryo kapag na-void.

            Paano magdagdag ng bagong user o cashier account?

            Pumunta sa Users tab (Admin access lang). Doon mo puwedeng magdagdag ng account at itakda ang role/permissions — halimbawa kung ano ang mga menu o feature na pwede o hindi ma-access ng isang cashier.

            Ano ang makikita sa User Logs?

            Ipinapakita rito ang history ng mga aksyon ng bawat user sa system — kung sino ang naglogin, nagbenta, nag-void, o gumawa ng pagbabago — para sa accountability at audit trail.

            Nakalimutan ko ang admin password, paano mag-reset?

            May reset option gamit ang One-Time PIN (OTP) na ipapadala sa naka-rehistrong Gmail. Kailangang naka-setup na muna ang Gmail App Password sa Receipt Settings bago gamitin ang feature na ito.

            Bakit kailangan ng Gmail App Password sa Receipt Settings?

            Ginagamit ang Gmail account (kasama ang App Password nito, hindi ang personal na password) para awtomatikong makapagpadala ng OTP email tuwing kailangan ng password reset o verification — kaya kailangan itong naka-setup nang tama.

            Kailangan ba ng internet para gumana ang OmniPOS?

            Karamihan sa mga pangunahing feature (checkout, inventory, reports) ay gumagana kahit lokal lang sa network. Pero ang mga feature na may kaugnayan sa email/OTP (tulad ng password reset) ay nangangailangan ng aktibong internet connection dahil dumadaan ito sa Gmail server.

            Paano ko malalaman kung may bagong bersyon ng OmniPOS at paano ito i-update?

            Pumunta sa Settings → System Update (Admin access lang), tapos pindutin ang "Check for Updates" para malaman kung may available na bagong bersyon. Kung meron, lalabas ang button na "Deploy Update Now" — pindutin ito para awtomatikong ma-apply ang update. Ligtas ang proseso at hindi mawawala ang iyong mga datos.
